Streamlit 基础概念

使用 Streamlit 很简单。先在普通的 Python 脚本中加入几个 Streamlit 命令，再用以下命令运行：streamlit run:

终端
streamlit run your_script.py [-- script args]

按上面的方式运行脚本后，本地 Streamlit 服务就会启动，应用会在默认浏览器的新标签页中打开。应用就是你的画布，可以在其中绘制图表、文本、交互组件、表格等内容。

页面具体展示什么，由你决定。例如，st.text可以向应用写入原始文本，而 st.line_chart顾名思义，会绘制折线图。请查阅API 文档，了解所有可用命令。

●

说明

向脚本传递自定义参数时，参数必须放在两个连字符之后；否则，它们会被当作 Streamlit 自身的参数。

还可以把 Streamlit 当作 Python 模块运行。在配置 PyCharm 等 IDE 时，这种方式可能很有用：

终端
# Running
python -m streamlit run your_script.py

# is equivalent to:
streamlit run your_script.py
★

提示

你也可以向 streamlit run 传入 URL！与 GitHub Gists 配合使用尤其方便。例如：

终端
streamlit run https://raw.githubusercontent.com/streamlit/demo-uber-nyc-pickups/master/streamlit_app.py

开发流程

每次需要更新应用时，请保存源文件。Streamlit 会检测变化，并询问是否重新运行应用。选择屏幕右上方的“Always rerun”（始终重新运行），之后每次修改源码时就会自动更新应用。

这样就能形成快速的交互式开发循环：写代码、保存、实时试用，再继续写一些代码、保存、试用，直到对结果满意。编码与查看结果之间的紧密循环，是 Streamlit 简化开发体验的方式之一。

★

提示

开发 Streamlit 应用时，推荐将编辑器和浏览器并排摆放，方便同时查看代码与应用。不妨试试看！

从 Streamlit 1.10.0 开始，应用不能从 Linux 发行版的根目录启动。如果这样运行，Streamlit 会抛出 FileNotFoundError: [Errno 2] No such file or directory 错误。更多信息请参阅 GitHub 问题 #5239.

如果使用 Streamlit 1.10.0 或更新版本，请将主脚本放在根目录以外的目录中。在 Docker 中，可以使用 WORKDIR 命令指定主脚本所在目录。示例请参阅创建 Dockerfile.

数据流

Streamlit 的架构允许你像编写普通 Python 脚本一样编写应用。为了做到这一点，它采用了独特的数据流：屏幕上的内容每当需要更新，Streamlit 就会把整个 Python 脚本从上到下重新运行。

这种情况可能在以下两种情形中发生：

  • 修改应用源代码时。

  • 用户与应用中的交互组件发生交互时，例如拖动滑块、在输入框中输入文本，或点击按钮。

通过交互组件的 on_change（或 on_click）参数传入回调函数时，回调总会先于脚本的其余部分运行。回调 API 的详细说明，请参阅会话状态 API 参考指南.

为了让这一切快速、顺畅地完成，Streamlit 会在后台承担许多复杂工作。其中一个重要角色是 @st.cache_data 装饰器，它使应用重新运行时能够跳过某些代价较高的计算。进阶概念中会更详细地介绍缓存。

AI 补充讲解

重新运行：为什么点一下，代码又执行了？

默认的数据流可以理解为：交互组件（widget）的值变化时，Streamlit 会重新从上到下执行脚本，再按最新输入刷新界面。

什么时候用：页面上有滑块、输入框或按钮，需要理解更新顺序时。

  1. 按从上到下的顺序组织代码。
  2. 把组件返回的值交给后面的计算和显示语句。
  3. 修改源码并保存后，可以按页面提示重新运行，开发时也可开启自动重新运行。
  • 这里解释默认整页运行方式；进阶的表单和局部重运行有各自规则。

展示数据与设置样式

Streamlit 提供多种方式展示表格、数组和数据表。下面将介绍 自动显示和 st.write()，它们能够输出文本、表格等多种内容。之后，我们再看看专门用于数据可视化的方法。

使用自动显示功能

即使不调用 Streamlit 的方法，也能向应用输出内容。Streamlit 支持“自动显示命令”，因此完全不必调用 st.write()！试试下面的代码，就能看到效果：

Python
"""
# My first app
Here's our first attempt at using data to create a table:
"""

import streamlit as st
import pandas as pd
df = pd.DataFrame({
  'first column': [1, 2, 3, 4],
  'second column': [10, 20, 30, 40]
})

df

只要 Streamlit 看到某个变量或字面量独占一行，就会自动使用 st.write() 将它显示在应用中。更多信息请参阅自动显示命令.

显示数据表

与 自动显示命令, st.write() 是 Streamlit 的“瑞士军刀”。你几乎可以向 st.write() 传入任何内容：文本、数据、Matplotlib 图形、Altair 图表等等。不必担心，Streamlit 会判断并正确渲染。

Python
import streamlit as st
import pandas as pd

st.write("Here's our first attempt at using data to create a table:")
st.write(pd.DataFrame({
    'first column': [1, 2, 3, 4],
    'second column': [10, 20, 30, 40]
}))

你也可以使用其他面向特定数据的函数，例如 st.dataframe() 和 st.table()，来展示数据。下面我们了解这些功能分别适用于什么情况，以及如何为数据表添加颜色和样式。

你可能会问：“为什么不一直使用 st.write()？”原因有以下几个：

  1. 自动显示和 st.write() 会检查传入的数据类型，并决定合适的渲染方式。但有时，你希望换一种方式展示。例如，不想把数据表显示成交互式表格，而是希望使用 st.table(df).
  2. 第二个原因是，其他方法会返回一个对象，你可以继续添加数据或替换数据，修改它的内容。
  3. 最后，使用更具体的 Streamlit 方法时，还可以传入额外参数，自定义其行为。

例如，我们来创建一个数据表，并用 Pandas 的 Styler 对象修改其格式。本示例将用 NumPy 生成随机样本，再通过 st.dataframe() 方法绘制交互式表格。

●

说明

本示例用 NumPy 生成随机样本，但也可以使用 Pandas 数据表、NumPy 数组或普通 Python 数组。

Python
import streamlit as st
import numpy as np

dataframe = np.random.randn(10, 20)
st.dataframe(dataframe)

接下来扩展第一个示例，使用 Pandas 的 Styler 对象突出显示交互式表格中的某些元素。

Python
import streamlit as st
import numpy as np
import pandas as pd

dataframe = pd.DataFrame(
    np.random.randn(10, 20),
    columns=('col %d' % i for i in range(20)))

st.dataframe(dataframe.style.highlight_max(axis=0))

Python
import streamlit as st

交互组件

准备好要探索的数据或模型后，就可以加入交互组件，例如 st.slider(), st.button() 或 st.selectbox()。方法很直接：把交互组件当作变量使用。

Python
import streamlit as st
x = st.slider('x')  # 👈 this is a widget
st.write(x, 'squared is', x * x)

首次运行时，上面的应用应输出“0 squared is 0”。之后，每次用户操作交互组件时，Streamlit 都会从上到下重新运行脚本，并把组件当前状态赋给相应变量。

例如，用户把滑块移动到 10 时，Streamlit 会重新运行上面的代码，并将 x 设置为 10。因此，此时应当看到“10 squared is 100”。

如果为交互组件指定了唯一字符串 key，也可以通过 key 访问它：

Python
import streamlit as st
st.text_input("Your name", key="name")

# You can access the value at any point with:
st.session_state.name

每个设置了 key 的交互组件，都会自动加入会话状态。有关会话状态、它与组件状态的关系及其限制，请参阅会话状态 API 参考指南.

使用复选框显示或隐藏数据

复选框的一种用途，是显示或隐藏应用中的某张图表或某个部分。st.checkbox() 接收一个参数作为组件标签。此示例通过复选框控制条件语句。

Python
import streamlit as st
import numpy as np
import pandas as pd

if st.checkbox('Show dataframe'):
    chart_data = pd.DataFrame(
       np.random.randn(20, 3),
       columns=['a', 'b', 'c'])

    chart_data

import streamlit as st

AI 补充讲解

把用户输入当作 Python 变量

滑块、复选框和下拉框会提供当前输入值。把返回值保存到变量，就能用平常的 Python 判断和计算控制页面。

什么时候用：需要选择筛选条件，或让用户决定是否显示一块内容时。

  1. 选择合适的输入组件，设置清楚的标签。
  2. 接住组件返回值，例如复选框返回的布尔值。
  3. 在后面的 if 判断中使用它，控制显示内容。
  • 给组件设置 key 后，可以通过 st.session_state 访问相关状态；这部分可继续阅读会话状态文档。

布局

使用 st.sidebar，可以轻松把交互组件放入左侧侧边栏。传给 st.sidebar 的每个元素都会固定在左侧，让用户在仍可使用控制项的同时，专注于应用的主要内容。

例如，要把下拉框和滑块放在侧边栏中，请使用 st.sidebar.slider和 st.sidebar.selectbox，代替 st.slider 和 st.selectbox:

Python
import streamlit as st

# Add a selectbox to the sidebar:
add_selectbox = st.sidebar.selectbox(
    'How would you like to be contacted?',
    ('Email', 'Home phone', 'Mobile phone')
)

# Add a slider to the sidebar:
add_slider = st.sidebar.slider(
    'Select a range of values',
    0.0, 100.0, (25.0, 75.0)
)

除了侧边栏，Streamlit 还有其他几种控制应用布局的方式。st.columns 可以把交互组件并排放置，而 st.expander 可以折叠大段内容，从而节省空间。

Python
import streamlit as st

left_column, right_column = st.columns(2)
# You can use a column just like st.sidebar:
left_column.button('Press me!')

# Or even better, call Streamlit functions inside a "with" block:
with right_column:
    chosen = st.radio(
        'Sorting hat',
        ("Gryffindor", "Ravenclaw", "Hufflepuff", "Slytherin"))
    st.write(f"You are in {chosen} house!")
●

说明

st.echo和 st.spinner 目前尚不支持放在侧边栏或布局选项中。我们正在努力增加这些支持，敬请放心！

显示进度

给应用加入耗时计算时，可以使用 st.progress() 实时显示状态。

先导入 time。我们将用 time.sleep() 方法模拟耗时计算：

Python
import time

现在创建一个进度条：

Python
import streamlit as st
import time

'Starting a long computation...'

# Add a placeholder
latest_iteration = st.empty()
bar = st.progress(0)

for i in range(100):
  # Update the progress bar with each iteration.
  latest_iteration.text(f'Iteration {i+1}')
  bar.progress(i + 1)
  time.sleep(0.1)

'...and now we\'re done!'
